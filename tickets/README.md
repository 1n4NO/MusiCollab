# MusiCollab ticket backlog

This is the implementation backlog for a personal project built to release-ready standards. Tickets are intentionally finer-grained than the eight phases so each behavior can be implemented, tested, and demonstrated independently.

## Workflow

- `planned`: not started
- `in-progress`: actively being built
- `blocked`: needs a decision, device, asset, or external service
- `done`: acceptance criteria verified

Priorities: `P0` release blocker, `P1` core product, `P2` important quality, `P3` polish.

## Definition of done for every ticket

The implementation is documented, tested at its relevant boundary, handles its failure state, and has no known regression on the supported Mac, iPhone 14, or iPhone 6 Plus Safari surface.
