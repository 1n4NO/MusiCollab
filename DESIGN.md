# MusiCollab Design System

## Direction

MusiCollab is a dark, studio-at-night instrument surface: the music controls
are the main visual material, with electric cyan for the shared clock and coral
for active performance. It refuses the generic dashboard/card layout by making
the transport and pads one continuous playable surface.

## Layout

- Portrait-first; landscape can be added once the two-device split is defined.
- Top transport stays visible while the playable pad area owns the screen.
- The smaller iPhone 6 Plus receives the same hierarchy with tighter spacing,
  never hidden core controls.
- Controls use at least 44pt touch targets.

## Visual tokens

- Background: near-black charcoal
- Primary text: white
- Secondary text: cool gray
- Clock/connection accent: electric cyan
- Performance accent: coral
- Sample accent: violet
- Surfaces: flat charcoal layers with restrained borders
- Typography: system San Francisco; bold only for tempo, section labels, and
  active musical state

## Interaction language

- Press-and-hold pads provide a visible active state.
- Transport uses familiar play/stop/record symbols.
- Import and slice are explicit actions with recoverable empty states.
- Motion is short and functional: pad glow, beat pulse, and slice selection.
