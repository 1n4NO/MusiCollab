# MusiCollab brand assets

- `musicollab-app-mark.svg` — iPhone/native app mark. The central connector is MusiCollab purple (`#8f5cff`).
- `musicollab-web-mark.svg` — web, Composer, Companion, and favicon mark.
- `musicollab-wordmark.svg` — light wordmark for dark surfaces.

Core palette:

- Charcoal: `#0b0e13`
- Cyan: `#2acfe5`
- Coral: `#ff5757`
- Purple: `#8f5cff`
- White: `#f5f7fb`

The marks are intentionally flat and geometric so they can be converted to
native app icon PNGs or monochrome variants without losing their silhouette.
